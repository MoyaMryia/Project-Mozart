# WOLA 静音启动修复

## 结论

2026-10-27，静音启动后的 WOLA 谱降噪已恢复。
静音 `100 ms` 后接 6 s 白噪声的试听样本，稳态衰减从 `0 dB` 提高到 `16.83 dB`。
用户确认的原始录音已重新经过原生 `mozart-pre`，新旧音频均保留。
完整摘要见 [metrics.json](metrics.json)。

## 原因与修复

旧实现使用首 8 帧功率初始化噪声估计。
数字零使该估计变为零，乘法上爬和最小值更新使零值持续保留。
长静音也会将已经建立的估计压到后验信噪比分母的数值地板以下。

C 和 Python 参考实现现在按频点累计前 8 个非零功率帧。
学习期间使用单位增益。
估计低于原有数值地板时，该频点重新学习。
输出队列仍按总帧数启动并排干，重学习保留输出节拍。
原有噪声参数、增益地板和前瞻配置保持不变。

## 回归结果

C/Python 普通夹具与静音前缀夹具的最大绝对差分别为 `2.42e-8` 和 `7.45e-9`。
对拍门槛仍为 `1e-6`；两组输出长度均与参考精确相等。

| C 测试输入 | 稳态噪声衰减 |
| --- | ---: |
| 直接白噪声 | 17.48 dB |
| 100 ms 静音后接白噪声 | 17.55 dB |
| 1 s 静音后接白噪声 | 17.55 dB |
| 1 s 白噪声、8 s 静音、再次白噪声 | 17.76 dB |

上述稳态统计排除噪声恢复后的首 1 s，沿用原有 `12 dB` 门槛。
默认测试电池与原始录音、espeak-ng 输入组成的附加电池均通过全部既有门槛。
主机原生测试为 `34/34`，状态测试另完成 10 轮重复。
主机 Python 测试完成 `424` 项；Jetson 原生与 WOLA Python 测试分别为 `7/7`、`11/11`。

VAD 测试现在先建立低电平噪声基线，再检查高信噪比突发。
reset 测试使用短突发，保留原有 `> 0.5` 功率比条件。
原测试的静音后持续白噪声构造会触发此次修复针对的锁零行为。

- 配置：Jetson Orin Nano Super 8GB；WOLA 窗长 128、步进 64、前瞻 0；高通开启，噪声门、AGC、限幅关闭。
- 原始录音：16 kHz 单声道，480007 个样本；SHA-256 为 `d7dafb12f8d444b2270f2d06158f47c235ca7892aaca1513561dc9971f2a8654`。
