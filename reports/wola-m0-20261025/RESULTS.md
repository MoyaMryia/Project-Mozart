## 结论

全部门限通过，部署候选配置定为 **frame=128 / hop=64 / lookahead=0**：

| 指标 | 门限 | 实测 |
| --- | --- | --- |
| 稳态噪声抑制（白噪） | ≥ 12 dB | 17.5 dB |
| 稳态噪声抑制（粉噪） | ≥ 12 dB | 13.5 dB |
| 稳态噪声抑制（50 Hz 哼声） | ≥ 12 dB | 18.0 dB |
| 稳态噪声抑制（风扇类） | ≥ 12 dB | 16.9 dB |
| 非稳态（键盘敲击） | 无门限，如实报告 | 0.0 dB |
| 高 SNR（≥15 dB）语音 SI-SDR 倒退 | 无 | 无 |
| 纯语音透明护栏 SI-SDR | ≥ −1 dB | 39.2 dB 与 120.1 dB（两段源） |
| 纯音乐透明 SI-SDR | ≥ 20 dB | 28.2 dB |
| 稳态发射延迟（128/64/0） | — | 4.00 ms |

噪声抑制行为纯噪声输入（幅度 0.05）的稳态口径：排除首 1 秒收敛区。
混合条件的全程能量差（`nr_all`）无门限，不在本表。

语音混合增强（SI-SDR 改善量，两段语音源取均值）：白噪 snr0 档 +8.9 dB、
snr10 档 +7.2 dB；粉噪 +1.4～+2.6 dB；哼声与风扇居中。
完整逐条数字见 `--json-out` 输出。

## 算法

WOLA（sqrt-Hann 50% 重叠，索引对齐重建）+ 决策导向维纳增益
（Ephraim-Malah 式先验 SNR 平滑，β=0.98）+ 噪声通道独立估计
（慢 EMA α=0.99、3 bin 频域平滑、最小值保持、门控慢上爬 0.0004/帧、
门控比 3.0）+ 增益地板 −18 dB。开局以首 8 帧功率均值初始化。

## 调参记录（五轮）

| 轮 | 改动 | 结果与教训 |
| --- | --- | --- |
| 1 | 谱减 + 快泄漏 | 噪声抑制 3.7 dB、音乐 LSD 16.9——帧级谱方差击穿最小值跟踪，快泄漏把和弦当噪声 |
| 2 | 加长平滑 | 改善有限——谱减结构本身不行 |
| 3 | 决策导向维纳 | 白噪 12.6 dB、SI-SDR 翻倍——方向正确 |
| 4 | 门控上爬 | 音乐透明修复，但门限 1.5 误伤纯噪声自适应 |
| 5 | 门限 3.0 + 均值初始化 + 队列排干 | 全过；初始化帧曾永久垫高驻留延迟 14.7→6.7 ms（lookahead=1） |

## 延迟四档（稳态发射延迟，喂入周期 128 样本）

| 配置 | 延迟 | 说明 |
| --- | ---: | --- |
| 256/128/1 | 10.67 ms | 质量余量最大，超预算 |
| 128/64/1 | 6.67 ms | lookahead 对指标无贡献（噪声通道本就慢速） |
| **128/64/0** | **4.00 ms** | **部署候选，全部门限同样通过** |
| 64/32/1 | 4.67 ms | 窗长 64 谱分辨率差，无优势 |

主机回路预算推算（B 拓扑：专用端点、无 Jetson aloop 跳）：
USB 项取两端实测往返中位 0.63 ms×2（见 USB 桥报告）。
128 样本设备周期时 2.67×2 + 1.26 + 4.0 ≈ 10.6 ms；
64 样本主机设备周期时 ≈ 7.9 ms。M3 端点手术时按此定设备周期。

## 已知边界

恒定单音与窄带哼声在估计器里不可区分，按设计被抑制——单测
`test_stationary_tone_suppressed` 钉死该特性。LSD 对近空 bin 的对数
放大敏感（纯音乐 LSD 21.5 dB 而 SI-SDR 28.2 dB），故透明门限定为
SI-SDR、LSD 仅报告。键盘类非稳态抑制为零，归 AI 分支神经级职责。

## 适用范围

- 配置：本机 x86_64；48 kHz；实现为 Python/numpy 参考版，C 实现待 M1 对拍。
- 样本：语音 2 段（48k DSP 输入、真人 qiqi 各 8 s）；噪声 5 类为确定性合成；音乐为合成和弦进行（无真实音乐语料）。
- 启动收敛段未验证。阻塞：电池指标排除首 1 秒，收敛时长未单测。解除条件：增加收敛时长用例后测量。

- 人工听感未验证。阻塞：缺少试听记录。解除条件：对保留样本逐段试听并记录。
- PESQ/STOI 未实现，以 SI-SDR 与 LSD 替代口径。阻塞：未引入对应实现。解除条件：引入后补测。
