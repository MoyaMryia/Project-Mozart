# 已连接 USB 的实机音频回路复测

日期：2026-10-26。设备为 `Bus 003 Device 020: ID 1d6b:0105 Linux Foundation FunctionFS Gadget`。
本轮使用已连接的 USB 线传输实际音频样本。

## 路径与方法

```text
本机完整 S16 音频块 → USB OUT → Jetson 高通＋WOLA
  → 输出 FIFO → USB IN → 本机读取对应音频块
```

主机为原生 C++/libusb，板端为现有 C DSP 测试泵。
配置为 48 kHz、双声道 S16、每块 64 个采样帧。
WOLA 窗长为 128，步长为 64，无前视；整形级关闭。
输入为确定性宽带噪声叠加正弦。

计时从主机提交完整输入块前开始，到读取对应完整输出块结束。
全部时间取自主机同一单调时钟。每包均检查序号、长度、时间戳和最终样本计数。
本轮沿用[原生 WOLA 试验](../native-wola-20261025/RESULTS.md)的客户端与参考校验方法。

## 结果

正式测量 60 s，前 100 包启动记录与后 16 包尾段记录单独保留。

板端独立日志确认接收并处理 45116 包，与主机计数一致。
分位数使用 nearest-rank，所有稳态最大值保留。
测试后两端 `mozart-usb-audio` 均恢复为 `active`，专用端点已释放。

## 工件

目录为 `rvc-golden/usb-connected-20261026/`：

- `b64-wola-60s/run.log`：主机记录的实际 USB bus/address 和运行结果。
- `b64-wola-60s/status.txt`：计数与延迟摘要。
- `b64-wola-60s/packets.csv`：全部逐包提交、返回和调度时间。
- `b64-wola-60s/input.raw`、`output.raw`：全部原始输入与实际回传输出。
- `b64-wola-60s/host-input-measured.wav`：正式测量区间的 60 s 输入。
- `b64-wola-60s/jetson-wola-return-measured.wav`：对应的实际 WOLA 回传音频。
- `jetson.log`：板端处理计数。

WAV 按协议包样本索引对齐，延迟使用 CSV 中的实际提交和返回时刻。
