## 诊断结果

当前 PCM 的峰值为 `-23.54 dBFS`。满量程样本数为 0，近峰值相邻重复值对数为 0。

低能量长窗中，`62.50 Hz`、`98.63 Hz` 和 `200.20 Hz` 有持续谱峰。
相对邻近谱的中位突出程度分别为 `11.78 dB`、`11.72 dB` 和 `27.01 dB`。
`200 Hz` 位于人声基频常见范围，主版本采用受限谱增益处理该区域。

时域检测得到 580 个孤立尖峰候选点。
本次通过频带控制处理高频粗糙感，并提供独立试听。

## 处理路径

现有降噪使用加权重叠相加（WOLA）。较强版额外使用短时傅里叶变换（STFT）。

```text
保守版：现有 80 Hz 高通和 WOLA → 6.8 kHz 四阶低通
        → 受限低频瞬态衰减 → 双阈值能量软门

较强版：现有高通和 WOLA → 低能量代理谱增益
        → 6.2 kHz 四阶低通 → 较强低频瞬态衰减 → 双阈值能量软门
```

C 算子在构造时预计算系数，在处理时复用状态。
本次保持主阶段原电平，另生成电平匹配文件。
四个匹配版本使用同一活跃帧集合，目标均方根（RMS）电平约为 `-32.01 dBFS`。

| 版本 | 低能量帧 RMS 相对现有降噪的变化 |
|---|---:|
| 原始输入，活跃帧电平匹配 | +3.73 dB |
| 现有降噪 | 0.00 dB |
| 保守清理，活跃帧电平匹配 | -3.03 dB |
| 较强清理，活跃帧电平匹配 | -4.24 dB |

静态窄陷波单独保留为未选中的实验。
在本录音的低能量核心区间内，陷波实验的最大电平增量为 `19.56 dB`。
主版本采用软门和谱增益，避开此次实验的尾迹。

三个处理版本均输出 1440021 个样本，采样率为 48 kHz，时长与原始文件相同。
输出全部有限，峰值均小于 0.09。

## 适用范围

- 配置：一份确认过的 30 秒录音，本机离线 CPU 处理，固定 48 kHz 输出。
- 样本数：1500 个完整 20 ms 分析帧。低能量集合为 225 帧，活跃集合为 983 帧。
- 测量覆盖原始 480000 个样本。剩余 7 个样本保留在输出中。
- 两类集合均由原始输入 RMS 阈值选择。它们是未人工标注的代理集合。
- 较强版用整段录音建立代理谱，并使用 1024 点中心窗、256 点步长。
- 差分文件包含增益和相位变化，用于定位受影响成分。
- 插值修复保持关闭。尖峰分类所需的事件标注见下述计划范围。
- 实际噪声源衰减和真实信噪比未验证。阻塞：缺配对干净参考；解除条件：取得同场配对参考。
- 采集端过载根因未验证。阻塞：缺原采集硬件、增益记录及编码前数据；解除条件：补充采集端实测。
- 事件标注、听感和实时验收范围统一见[实施计划](../../docs/FAST_VOICE_DSP_PLAN.md#适用范围)。
