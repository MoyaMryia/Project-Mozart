# 项目扫描与可靠性修复

日期：2026-10-13。代码基线：`adc595c`。本轮修复下表中的 9 类问题，并更新部署文档及回归检查。
扫描范围包括 HTTP 接口、文件队列、模型加载、预处理、IO、字幕/播报工具、前端和持续集成（CI）。
检查侧重已有故障证据、异常输入和资源生命周期。没有修改 RVC 张量计算、模型导出或资产权重。

请求上限：请求头 16 KiB，完整 HTTP 请求 110 MiB，单个音频文件 100 MiB。
活动请求数据共享 128 MiB 配额。该配额不包含字符串容量、响应或模型内存，不是进程总内存上限。

读取、写入截止时间不会因持续少量传输而重置。
