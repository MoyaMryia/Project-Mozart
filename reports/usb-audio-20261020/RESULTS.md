# USB 全双工音频桥验证

日期：2026-10-20，新加坡时间。
在 Jetson 与工作站之间用 USB bulk 端点建立全双工音频通道，两端各接一张 `snd-aloop` 虚拟声卡。
设计与安装步骤见 [usb-audio/README.md](../../usb-audio/README.md)。

## 结论

通道可用：双向音频内容正确，10 分钟受压无丢帧、无服务重启、无 DMA 报错。
管线只需替换两个设备名即可接入，代码零改动。

## 传输层

FunctionFS gadget `1d6b:0105`，端点 OUT `0x01` / IN `0x82`，高速 bulk 512 字节包。

| 项目 | 数值 |
| --- | ---: |
| 吞吐 | 40 MB/s |
| 往返延迟中位 | 0.63 ms |
| 往返延迟 P95 | 0.76 ms |
| 往返帧数 | 3000 / 3000 |
| 60 s 浸泡 | 无异常 |

单次收发测试发送 150 帧、接收 187 帧，序号缺口 0。
控制帧（`STATS`，10 字节负载）与 PCM 复用同一对端点。

## 音频内容校验

用 1 kHz 正弦判断链路是否真的传输音频，不只统计帧计数。

| 方向 | 结果 |
| --- | --- |
| 主机虚拟扬声器 → Jetson 管线麦克风 | −27.1 dBFS，全程保持 |
| Jetson 管线扬声器 → 主机虚拟麦克风 | −15.7 dBFS，5.00 s |

## 10 分钟受压

输入为 6 s 中文合成语音，循环 40 轮，共 640 s。管线按完整模式运行 ASR、翻译与 TTS。

| 项目 | 主机 | Jetson |
| --- | ---: | ---: |
| 发送帧（累计） | 56166 | 55567 |
| 接收帧（累计） | 55517 | 56191 |
| 丢弃 | 0 | 31（启动前离线期） |
| 服务重启 | 0 | 0 |

受压窗口内双向计数差不超过 44 帧，折合 0.9 s，属在途缓冲。

管线侧：字幕 426 条，日志无异常。回传录音检出 57 个播报段，时长中位 1.00 s，峰值 −3.1 dBFS。
`dmesg` 在受压期间新增 0 条 `tegra-mc`、`fsr=0x402`、`xudc` 错误。

## 拔插恢复

在受压结束后物理拔出并重新插入 USB-C 线。

主机侧记录 `USB 断开 ... （离线模式）`，随后 `USB 就绪 out=0x01 in=0x81`。
Jetson 侧记录 `disabled；等待重新启用`，随后 `enabled`。
两端服务均未重启，帧计数继续增长。
复测音频为 −15.7 dBFS，与拔插前一致。

## 管线接入

`tools/run_translated_speech.py` 增加两个环境变量默认值，未设置时行为与之前一致。
Jetson 上的实测参数：

```bash
MOZART_MIC_DEVICE=plughw:CARD=Loopback,DEV=1,SUBDEV=0
MOZART_PLAYBACK_DEVICE=plughw:CARD=Loopback,DEV=0,SUBDEV=1
```

## 适用范围

配置：工作站与 Jetson Orin 各一张 `snd-aloop`；Jetson 设备 `plughw:CARD=Loopback,DEV=0,SUBDEV=0` 与 `SUBDEV=1`；VID:PID `1d6b:0105`；48 kHz 立体声、20 ms 帧长；两端守护进程经 systemd 启动。
样本：传输层 3000 帧往返与 60 s 浸泡；音频内容校验各 1 次；受压 640 s、40 轮输入、1 份 640 s 回传录音；拔插恢复 1 次。
未验证项：真实人声的识别与播报质量，阻塞：输入为合成语音，解除条件：用同一设备名复测一段真人录音。
未验证项：连续运行超过 10 分钟，阻塞：本轮受压时长固定为 640 s，解除条件：跑一次 30 分钟受压并统计丢帧。
未验证项：主机重启后 Jetson 侧自动重连，阻塞：本轮只测了拔插，解除条件：重启工作站后确认两端服务自启且帧计数恢复。
