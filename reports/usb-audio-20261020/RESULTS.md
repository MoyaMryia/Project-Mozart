# USB 全双工音频桥验证

日期：2026-10-20，新加坡时间。
在 Jetson 与工作站之间用 USB bulk 端点建立全双工音频通道，两端各接一张 `snd-aloop` 虚拟声卡。
设计与安装步骤见 [usb-audio/README.md](../../usb-audio/README.md)。

## 结论

通道可用：双向音频内容正确，640 秒受压期间无服务重启、无端点错误、无内核 DMA 报错。
管线只需替换两个设备名即可接入，代码零改动。

## 测量方法

- 端点回环：`ffs-echo` 收到帧后原样回写，主机记录发送到回写的间隔。
- 音频链路：主机播放 1 kHz 正弦到虚拟扬声器，另一端录制并计算 RMS。
- 受压：主机循环播放 6 秒中文合成语音，管线运行完整模式，两端守护进程每 2–5 秒打印计数。
- 帧计数与缺口：[usb-audio/bench.py](../../usb-audio/bench.py) 发送带序号的 PCM 帧并统计回传。

## 传输层

FunctionFS gadget `1d6b:0105`，端点 OUT `0x01` / IN `0x82`，高速 bulk 512 字节包。

| 项目 | 数值 |
| --- | ---: |
| 端点吞吐 | 40 MB/s |
| 往返延迟中位 | 0.63 ms |
| 往返延迟 P95 | 0.76 ms |
| 回环帧数 | 3000 / 3000 |
| 60 秒浸泡 | 无端点错误 |

控制帧与 PCM 复用同一对端点，接收方按类型分流。

## 音频内容校验

用 1 kHz 正弦判断链路是否真的传输音频，不只统计帧计数。

| 方向 | 结果 |
| --- | --- |
| 主机虚拟扬声器 → Jetson 管线麦克风 | −27.1 dBFS，全程保持 |
| Jetson 管线扬声器 → 主机虚拟麦克风 | −15.7 dBFS，5.00 秒 |

## 640 秒受压

输入为 6 秒中文合成语音，循环 40 轮。管线按完整模式运行识别、翻译与合成。

计数为进程启动以来的累计值，两端起点不同，不能直接相减。

| 项目 | 主机 | Jetson |
| --- | ---: | ---: |
| 发送帧（累计） | 56166 | 55567 |
| 接收帧（累计） | 55517 | 56191 |
| 丢弃 | 0 | 31（启动前离线期） |
| 端点错误 | 0 | 0 |
| 服务重启（systemd NRestarts） | 0 | 0 |

管线侧：字幕 426 条，日志无异常。回传录音检出 57 个播报段，时长中位 1.00 秒，峰值 −3.1 dBFS。
`dmesg` 在受压期间新增 0 条 `tegra-mc`、`fsr=0x402`、`xudc` 错误。

## 30 分钟受压

输入为 1800 秒视频，管线完整模式，播放经 USB 桥回到主机；主机侧循环喂入 21.7 秒中文语音，
每轮间隔 2 秒，同时录制虚拟麦克风。受压窗口约 19 分钟，两端计数在同一时刻采样。

| 方向 | 发送 | 接收 |
| --- | ---: | ---: |
| 主机 → Jetson | 57913 | 57931 |
| Jetson → 主机 | 55104 | 55086 |

差值 18 帧，折合 0.36 秒，与两次采样的时间差同量级。受压窗口内丢弃与缺口计数不变。

管线侧：最终分段 367，译文完成 356，失败 11；收到至译文完成中位 0.80 秒，P95 2.28 秒。
回传录音 1830 秒，非静音 956 秒（52%），峰值 −0.8 dBFS。
`dmesg` 无新增 `tegra-mc`、`fsr=0x402`、`xudc` 错误，仅保留 10 月 13 日开机记录。

## 拔插恢复

受压结束后物理拔出并重新插入 USB-C 线。

主机侧记录 `USB 断开`，随后 `USB 就绪 out=0x01 in=0x81`，端点地址由内核重新分配。
Jetson 侧记录 `disabled；等待重新启用`，随后 `enabled`。
两端服务均未重启，帧计数继续增长。
复测音频为 −15.7 dBFS，与拔插前一致。

## 管线接入

`tools/run_translated_speech.py` 增加两个环境变量默认值，未设置时行为与之前一致。

```bash
MOZART_MIC_DEVICE=plughw:CARD=Loopback,DEV=1,SUBDEV=0
MOZART_PLAYBACK_DEVICE=plughw:CARD=Loopback,DEV=0,SUBDEV=1
```

## 适用范围

配置：工作站与 Jetson Orin 各一张 `snd-aloop`；Jetson 设备 `plughw:CARD=Loopback,DEV=0,SUBDEV=0` 与 `SUBDEV=1`；VID:PID `1d6b:0105`；48 kHz 立体声、20 ms 帧长；两端守护进程经 systemd 启动。
样本：端点回环 3000 帧与 60 秒浸泡；音频内容校验各 1 次；受压 640 秒与 1800 秒各 1 次，后者含 19 分钟双向计数窗口与 1830 秒回传录音；拔插恢复 1 次。
真人语音校验：视频第 63–123 秒（真人讲述），识别 261 字、人工字幕 267 字，字符相似度 0.909；
12 个分段译文完成 11 个。脚本为 `usb-audio/verify-human-voice.sh`。
重连校验：重启主机侧守护进程后两个方向恢复出帧，脚本为 `usb-audio/verify-reconnect.sh`。
整机重启校验：主机重启后 45 秒自检，主机侧 `发 8100 收 8102 丢 0`，
Jetson 侧 `发 13996 收 13982`，缺口 1，两端均自动恢复。
Jetson 的发送看门狗在重启过渡期触发一次重开端点（错误计数 27），随后恢复出帧。
自检结果见 `/var/log/mozart-usb-reconnect.log`。
