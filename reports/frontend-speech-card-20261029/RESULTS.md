# 播报卡片布局与启停交互

本次修改移除了播报卡片外层的隐藏滚动区域。
音色、输出和启停控件默认展开；上传、试听、历史任务和系统日志使用独立折叠区。

## 交互修改

- 主栏按内容高度排列播报卡片。桌面保留主栏滚动条，手机使用页面滚动。
- 播报控制条在卡片范围内吸顶。展开历史任务后，用户仍可操作停止按钮。
- “禁用翻译播报”和“应用音色与输出”使用独立按钮。
- 禁用请求只发送 `enabled: false`，保持服务器现有音色和输出设置。
- 停止按钮中断正在等待的普通请求，再发送停止请求。
- 被取消的旧文件读取结束后，工作状态仍归属于新操作。
- 请求失败保留错误原因。程序错误向上抛出。
- 中文字幕使用 16 px 正文并完整换行；英文使用 14 px 正文。
- 系统日志默认只显示折叠标题，展开后在日志区滚动。

## 本地验证

浏览器脚本使用模拟 API，检查真实构建页面。
每个可见性断言同时检查位置与命中元素，避免把被裁剪的按钮判为可操作。

| 检查 | 结果 |
| --- | --- |
| 桌面默认播报开关与停止按钮 | 位于视口内，可命中 |
| 手机默认播报开关与停止按钮 | 位于视口内，可命中 |
| 手机展开历史并滚至最后一项 | 控制条保持可见 |
| 试听请求挂起时停止 | 停止按钮可操作，试听请求被取消，停止请求已发送 |
| 修改音色后的禁用入口 | 禁用和应用按钮同时存在 |
| 日志折叠 | 卡片高度为 33 px，隐藏内容占位为 0 px |
| 长句字幕 | 中文完整换行，两个视口均未横向裁剪 |

前端自动测试共 52 项，全部通过。
测试包含旧请求取消、迟到文件读取、禁用草稿隔离、停止部分失败、请求错误分类与程序错误传播。

## 复现

```bash
bash tools/ci-local.sh frontend
MOZART_TEST_CHROMIUM=/path/to/chrome \
  node frontend/tests/browser/speech-layout.mjs /tmp/mozart-speech-layout
```

浏览器脚本创建本地模拟接口，并在退出时关闭自建浏览器和接口。
断言失败时，脚本返回非零退出码。

## 适用范围

- 配置：本地 Chromium `151.0.7922.34`，`1366 × 768 px` 桌面视口和 `390 × 844 px` 手机视口。脚本阻止外部字体请求。
- 样本：52 项前端自动测试；浏览器使用 1 组中英文长字幕、6 条模拟完成任务和 1 次挂起试听请求。
- 本轮调整范围为播报卡片、字幕和日志布局及对应请求边界。
- 实际播放和整链路验证条件见[播报投递报告](../speech-delivery-semantics-20261028/RESULTS.md#适用范围)。
