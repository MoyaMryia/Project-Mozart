# 端到端延迟实测：≤10 ms 要求的达成与口径

日期：2026-10-25。响应验收要求"音频输入到输出端到端延迟 ≤10 ms（实时演奏级）；
延迟稳定无抖动"。

## 实测方法

Jetson 实机，双 aloop 电缆隔离法（采集/直出分用不同 substream，消除自激）：
源脉冲（非周期，互相关无歧义）→ 电缆 1 → mozart-pre 采集 → WOLA →
直出 → 电缆 2 → 回录。全局互相关测绝对延迟；每配置重跑两次验证复现性。

## 结果

| 配置 | 端到端（含测试电缆） | 复现性 |
| --- | --- | --- |
| period 64，降噪开 | **12.0 ms** | 第二次运行 12.0 ms（完全一致） |
| period 64，降噪关（旁路） | 12.0 ms | 与降噪开启无差 |
| period 128，降噪开 | 16.0 ms | — |

测试口径含源 aplay 的 aloop 电缆（约 4 ms）——产品路径中这部分不存在
（真实麦克风直入声卡）。

## 产品口径换算

端到端 = 麦克风采集 period + WOLA + 播放 period + DAC/USB 延迟：

| 配置 | 软件链 | + DAC/USB ~1.5 ms | 判定 |
| --- | --- | --- | --- |
| **period 64（建议默认）** | 1.33 + 4.0 + 1.33 ≈ 6.7 ms | **≈ 8.2 ms** | ✅ ≤10 ms |
| period 128（现默认） | 2.67 + 4.0 + 2.67 ≈ 9.3 ms | ≈ 10.8 ms | ❌ 贴线超限 |

WOLA 发射延迟 4.0 ms 是 (128,64,0) 配置；(64,32,0) 配置已验证全门限通过
（抑制 12.9–18 dB、音乐 SI-SDR 40 dB、发射 3.33 ms），作为再省 2 ms 的备用。

## 抖动

非周期脉冲互相关两次运行完全一致（12.0/12.0 ms）；period 128 与 64 的读数
各自稳定（16.0 与 12.0）。软件段（`direct_us`）avg 5–6 µs、max <100 µs。
软件链路无可测抖动；DAC/USB 段待真机声学回录终验。

## 主机回路（不进 ≤10 ms 口径）

主机回路（声音经 USB 至主机）无法满足 ≤10 ms：2 个时钟域 + 4 个 period
边界 + USB 往返 + 处理的物理地板已超 10 ms，且 Python 守护进程的调度
抖动不可控。回路定位为监视/控制通道（修复后稳态 205 ms，方差 <1 ms，
见[回路排查](../loop-latency-20261025/RESULTS.md)）。演示走位：麦克风与
耳机接 Jetson，主机仅作控制台。

## 结论

1. `--period-frames 64` 作为演示默认值（8.2 ms，留 1.8 ms 余量）。
2. period 64 下 Jetson 实测零 overrun（本次与 M1 冒烟一致）。
3. 终验待办：真实声卡（PCM2902）声学回录，量含 DAC 的真实端到端。

## 适用范围

- 配置：Jetson Orin 实机、snd-aloop 双电缆、`--no-denoise` 与降噪各测。
- 样本：period 64 两组、period 128 一组（各 6–7 s 非周期脉冲）。
- DAC/USB 段为估算（~1.5 ms），未实测。阻塞：声学回录接线未接。
  解除条件：接 PCM2902 回录后按同法测量。
