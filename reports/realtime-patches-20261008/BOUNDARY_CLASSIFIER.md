# 小型句界分类器实测

日期：2026-10-09。连接：`ssh jetson-wg`。
代码基于 `d16121f` 的未提交工作快照。两组实际 Python 文件与原生程序摘要相同。

本轮分类器实验降低了首播等待，原文提交范围覆盖 23／23 句。
功能使用显式开关，默认关闭。结果来自同一段 120 s 录音的单次对照，不能代表所有输入。
用户允许较粗糙的翻译与切分；本轮仍保留全部原文、最终尾句、顺序播报和失败提示。

## 模型与实现

采用 NNSplit 0.5.8 的中文句界模型，权重为 4,062,819 字节。
模型与参考实现采用 MIT 许可证；原文见 [NNSPLIT.txt](../../tools/licenses/NNSPLIT.txt)。
上游版本固定为 [`7193727df7e497b0993ad96688f34c3a6add0618`](https://github.com/segment-any-text/wtpsplit/tree/7193727df7e497b0993ad96688f34c3a6add0618)。
下载程序直连 GitHub，并验证下列 SHA-256：

```text
6cfdf98b039e38e84f7efea279b87666de12b3928576a1b331a0c8260eb34894
```

分类器使用 ONNX Runtime 的 CPU 单线程。它在独立线程中判断稳定原文的切分位置。
等待区只保留最新请求；晚到结果须重新核对当前原文与已提交范围。
分类器不调用 Qwen 判断语义。模型预测句界，不能证明意思完整。

本轮阈值为 `0.5`。前缀至少经过两次观察，观察跨度至少为 200 ms。
每次提前提交至少 8 个字符，切分位置之后保留至少 4 个稳定字符。
新增稳定原文达到 28 个字符时，即使没有合格句界，也允许按长度限制切分。
长度限制为 24 个字符；切分选择 8–24 字符范围内得分最高的位置。
每句最多提前提交 8 次，最终识别提交全部剩余原文。

若识别改写已提交前文，系统等待最终结果，并提交带明确提示的更正。
分类器错误保留原字幕和警告，最终翻译继续处理剩余文字。
翻译检查失败的非空候选仍显示并播报。
参数、队列和回退方法见[使用说明](../../docs/SIMULTANEOUS.md#小型句界分类器实验)。

## 测试配置与计时

设备为 Jetson Orin Nano Super。图形服务保持运行。
识别使用 Zipformer 14M；翻译使用 Qwen 0.8B Q4_K_M，运行于 GPU。
PocketTTS 使用 CPU int8、2 线程、五步生成、种子 42 和既有 Qiqi 参考 WAV。
两组均启用提前输出音频，使用同一独立 sherpa-onnx 1.13.6／ONNX Runtime 1.27.1 运行时。
分类器的 Python ONNX Runtime 版本为 1.27.0。
输入使用保留的预处理 WAV，不重复执行 RNNoise；RVC 关闭。

对照为 `boundary-control-v1`，分类器实验为 `boundary-v1`。
两组依次执行，使用共享测试锁，每组只运行一次。
源 WAV、参考 WAV、翻译模型、Python 文件和原生程序摘要保存在[汇总数据](boundary-results.json)。
两组最终识别原文逐句相同，共 23 句。
协议没有记录 TTS 模型摘要；本轮沿用同一设备资产与运行时，不能将其视为完整资产清单。

“首播等待”从原句最终识别事件发出计时，到该原句首个音频块开始播放。
负值表示在最终识别事件前已经开始播放。
该计时不含说话至识别事件的等待，不是说话至扬声器出声的总延迟。
播放目标为按音频时长等待的 ALSA `null`；本轮没有实体声卡测试或人工听检。

“分类判断耗时”从输入打包前计时，到模型推理及切分选择完成。
统计只包含字幕日志中接受的 101 次结果，不含模型加载、排队或丢弃的过期结果。
该指标不能直接代表完整链路增加的延迟。

分类器在 10／23 句中提前提交，共提交 18 个片段。
其中 14 个片段使用模型句界，4 个片段使用长度限制。
提前提交至最终识别事件的时间差，中位数为 2.389 s，范围为 0.621–7.981 s。
101 次接受的分类判断耗时中位数为 8.76 ms，范围为 4.02–17.72 ms。
本轮没有分类错误，也没有触发原文更正。

两个总体首播等待中位数相差 2.371 s。
按相同原句配对，实验减对照的差值中位数为 −4.534 s，范围为 −14.159 至 +2.531 s。
这些统计的含义不同，不能理解为每句都减少固定时长。
第 6 句增加约 2.531 s；多数句子仍需等待已有播报任务。

本轮输出总长减少 7.20 s，英文词数减少 29 个。
提前提交改变了翻译表达与播报长度，因此不能把全部收益归因于提前开始计算。
123.60 s 输出仍长于 120 s 输入，持续输入时仍可能积压。
本轮没有改变播放速度。

## 覆盖、连续性与限制

实验 23／23 份父字幕的片段范围连续，按序连接等于完整最终原文。
这证明提交没有漏字，不证明识别正确或译文保留全部事实。
第 5 句仍有中文残留，翻译检查失败；候选文字和语音均已输出。
对照与实验各有 22／23 句通过自动检查；该检查不是语义质量验收。

23／23 份对照 WAV、41／41 份实验 WAV 均等于各自音频块的有序连接。
满幅样本数为零，播放顺序正确，字幕修订号没有回退。
实验出现 2 处超过 20 ms 的原句内部间隙，最大值为 25.34 ms。
本轮没有人工听检，不能据此保证听感连续性。

两组退出状态均为 0，等待与未完成播报任务均为零。
存储警告、预热错误和测试残留进程均为空。
原设备仓库保持在 `fd9a0fc`。原仓库和模型资产未修改。

最终代码在本地和 Jetson 均通过 147 项 Python 回归。
前端 8 项测试与生产构建通过。
回归覆盖慢分类、过期结果、原文改写、错误降级、请求替换和最终尾句。

本轮使用的独立模型文件通过固定 SHA-256 验证。
下载脚本校验并复用已有模型的检查通过。
下载脚本在 Jetson 上的额外新下载检查等待较久，已主动停止。
该检查没有完成，不能据此确认脚本在设备上的新下载流程已经通过。

本轮支持保留该可选实验路径。它仍未实现稳定的同声传译时延。
后续应增加不同语速和更长输入的回放，区分切分收益与译文缩短带来的收益。
若要继续降低延迟，需要同时处理语音生成与播放积压；继续缩短片段未必有效。
