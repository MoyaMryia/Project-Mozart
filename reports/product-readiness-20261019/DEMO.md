# 十一月初现场演示方案

更新日期：2026-10-19。
用户暂定十一月初进行现场演示，具体日期待定。

近期交付目标为一套声音效果突出、操作完整、能够恢复的演示版本。
用户希望利用演示前的时间，把已有功能的关键细节做完整。
交付审核的 16 组问题全部纳入收尾，按现场影响、依赖顺序和验证成本处理。
短演示主流程用于介绍能力，实际版本同时覆盖日常操作、异常处理和持续运行。

## 观众体验

主流程控制在约 90–120 s，实际时长以彩排为准。

| 环节 | 现场动作 | 观众感受到的能力 |
| --- | --- | --- |
| 1：声音变化 | 演示者说同一句短中文，切换原声与已验收音色 | 说话方式保留，声音发生明显变化 |
| 2：跨语言输出 | 演示者说一句完整中文，屏幕显示原文和英文，设备播出英文 | 从说中文到英文出声的完整过程 |
| 3：现场互动 | 邀请观众提供一句短句，再执行完整流程 | 展示实际输入带来的输出变化 |

使用一个经过试听确认的音色完成主流程。
英文播报接入实时 RVC 属于目标链路，接入后核对英语发音、音色和播放等待。
界面以原文、英文、当前处理状态和播放状态为主。
模型路径、详细参数和调试日志折叠到操作区。
声音、字幕和状态均来自实际处理结果。

## 演示前优先完成

1. 确认物理输入、输出和监听电平，提供可重复的出声检查。
2. 统一模型预热与就绪状态，完成后允许开始演示。
3. 修复客户端重连和无声故障，提供明确错误及重新开始入口。
4. 扩展上下文对照，处理重复译文、口语数字和已复现的合成失败。
5. 接入英文播报实时变声，核对串接前后的内容、音质、时长和资源。
6. 制作演示界面，放大双语内容，明确显示当前工作状态。
7. 补齐任务取消、下载、音色选择、配置检查、字幕重连及存储状态。
8. 固定运行环境、资产清单和启动步骤，提供日志导出与恢复操作。
9. 完成同一套配置的整场彩排、重复启停和完整文件联合测试。

对应代码问题见[交付审核](RESULTS.md) D01–D16。
PipeWire、零样本转换及增加其他模型列为后续扩展。
演示使用固定设备和配置，控制页面通过本机或受控连接访问。

## 细节完成标准

| 范围 | 收尾标准 |
| --- | --- |
| 声音 | 原声和变声可对照；英文可懂；停止后无残留播放 |
| 内容 | 数量、否定、人称和重复内容有固定回归；保留失败分母 |
| 操作 | 启动、停止、重新开始、取消、下载和音色选择均有完整流程 |
| 状态 | 预热、就绪、等待、播放、故障和恢复状态与实际行为一致 |
| 异常 | 声卡失效、客户端重连、服务退出和非法配置得到明确处理 |
| 持续运行 | 检查队列、丢帧、欠载、内存、swap、存储及历史保留 |
| 交付 | 使用固定资产和环境启动，保留版本清单、日志及恢复步骤 |

## 素材与互动准备

准备 6–10 条短中文素材，覆盖自我介绍、场景介绍、简单问答和一句带数量的表达。
逐条保存原始输入、实际识别、译文和输出音频。
检查内容完整、英语可懂、音色稳定及首音等待。
先验证固定句，再用现场新录的同类短句彩排。

另准备一份完整流程录屏和原声／变声试听。
备用素材标明“录制样例”，由演示者显式切换。
现场故障保留错误状态及日志。

## 排期建议

| 阶段 | 重点 | 产物 |
| --- | --- | --- |
| 第一阶段，约 3 天 | 出声、启动、重连、配置及运行状态 | 可重复使用的物理链路和正确故障反馈 |
| 第二阶段，约 3–4 天 | 翻译积压、英文实时变声及听感对照 | 完整主流程和逐条试听记录 |
| 第三阶段，约 3–4 天 | 界面操作、任务与存储、部署清单及联合测试 | 完成审核问题复核的演示候选 |
| 演示前预留约 2–3 天 | 冻结配置、重复彩排和备用录制 | 固定版本、操作卡和录制样例 |

每个阶段使用独立证据目录，保留首次输出和全部失败。
准确日期确定后，再将以上阶段映射到日历。

## 彩排验收

- 主流程连续成功执行 3 次，保留每次运行结果。
- 逐条核对全部演示素材的识别、译文和声音。
- 测量中文说完至英文首音的等待，按实际输出说明体验。
- 验证停止、再次开始和麦克风客户端重启。
- 验证错误输出设备得到明确提示，恢复后重新出声。
- 验证任务取消、结果下载、音色选择、字幕重连及服务退出。
- 核对启动环境、资产清单、错误状态和日志导出。
- 使用最终整机配置执行完整文件联合测试，完成后再次彩排。

## 适用范围

- 配置：计划使用 Jetson Orin Nano Super 8GB、已验证的 Qiqi 实时模型、现有识别／翻译／PocketTTS 路径及实际声卡。
- 样本：本文件是排期与演示设计，新增实测样本为 0；既有测试由[审核报告](RESULTS.md)索引。
- 演示确切日期未确定。阻塞：用户暂定十一月初。解除条件：取得具体日期后调整彩排与冻结时间。
- 英文实时变声和最终素材听感未验收。阻塞：生产链路接入及人工试听尚未完成。解除条件：按第二阶段保留对照音频并完成确认。
