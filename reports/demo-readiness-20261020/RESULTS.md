## 板端短测

输入使用既有完整录音解码结果的前 20 s，开启原生预处理，输出到 ALSA `null`。

| 指标 | 实测结果 |
| --- | --- |
| 输入与返回包 | 1000/1000；序号为 1–1000，重复、乱序、坏包均为 0 |
| 推理块 | 83 块；日志计数与状态计数一致 |
| 完整块耗时 | 中位数 64.397 ms，P95 64.886 ms，最大 66.745 ms |
| 推理与调度 | 推理错误、迟到、跳块、输入溢出、输出溢出和传输丢弃均为 0 |
| 欠载 | 启动欠载 20 帧；运行期新增欠载 0 帧 |
| 可用内存 | 采样最小值 5.105 GiB |
| swap | 使用量保持 283377664 B；换入 9 页，换出 0 页 |
| 音频捕获 | 输入 320000 个 16 kHz 样本，返回 960000 个 48 kHz 样本，均为 20 s |
| 返回音频 | 峰值 0.978910，非有限和超满幅采样均为 0 |
| 回收 | 控制器退出码 0，强制回收为空 |

试听：[预处理后输入](../../rvc-golden/demo-readiness-20261020/previews/source-processed.mp3)、[实时变声返回](../../rvc-golden/demo-readiness-20261020/previews/qiqi-realtime-backend.mp3)。
