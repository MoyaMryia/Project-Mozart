# 彩排与故障恢复

使用已配置的设备和固定输入彩排。启动与停止命令见[运行手册](RUNBOOK.md)。
本页保留三轮、每轮 15 分钟的验收安排；执行时保存每轮结果。

## 启动前

1. 记录提交、模型、实际推理后端和音频设备。
2. 核对两个原生构建目录与实际启动的二进制。
3. 检查 USB 桥服务和双向计数。
4. 确认现有语音实例和端口占用。
5. 选择变声输出或译文播报。

直出、变声和播报按各自路径验收。USB 快流使用独立端点时，先按[USB 手册](../usb-audio/README.md)检查挂载与权限。

## 每轮清单

| 项目 | 操作与记录 |
| --- | --- |
| 冷启动 | 检查两端 USB 服务恢复；记录实际恢复时间，目标为 45 s 内恢复出帧 |
| 变声与字幕 | 使用统一入口启动，核对同一次采集的变声输出和中英字幕 |
| 译文播报 | 停止后切换到播报输出；核对参考音色、译文、声音与任务状态 |
| 语音停止与恢复 | 页面停止播报后检查字幕继续，再准备并启用会话 |
| 设备切换 | 修改草稿，等待轮询，应用后核对实际设备和声音 |
| 直出与降噪 | 使用独立预处理配置，对照处理开关并保存录音 |
| 路由压力 | 在具备后端回包的配置下切换 direct 与 ai 共 20 次，记录断流与爆音 |
| 拔插 | USB-C 拔插 3 次，记录双向计数恢复与错误变化 |
| 断网 | 按既定离线方案断网，检查本地音频和模型服务；控制台另行记录连接情况 |
| 停止 | 使用入口 stop，确认受管进程和声卡句柄释放 |

## 延迟与覆盖

直出目标为端到端不超过 10 ms，阶段验收上限为 12 ms；p99 与中位数差值目标不超过 1 ms。
计时边界、软件段证据与声学测量条件见[预处理设计](../DESIGN_PREPROCESSOR.md#构建与验收)。
采集 period、处理统计、播放时间戳与声学回录分别记录。
变声和播报使用各自的计时范围，字段定义见[延迟说明](REALTIME_LATENCY.md)。

对每段原文记录翻译、受理、合成与播放的结果。
失败、取消、跳过与到期均计入覆盖统计，并保留错误原因。

## 故障恢复

先保存状态、错误和输入，再定位第一个异常组件。

| 故障 | 定位证据 | 恢复动作 |
| --- | --- | --- |
| USB 无帧 | 两端服务、端点及帧计数 | 按 USB 手册恢复对应端点或服务 |
| 采集失败 | 设备状态、ALSA 错误和占用进程 | 释放冲突设备，再重启预处理 |
| 后端失败 | 启动日志与退出码 | 修复资产或运行时原因后重启受管链路 |
| 无字幕 | 输入包计数、JSONL 与 SSE | 恢复首个停止增长的环节 |
| 无播报 | 会话、运行时和任务错误 | 恢复准备状态，检查已受理任务结果 |
| 延迟增长 | 队列水位、处理耗时和播放等待 | 按时间线定位积压来源后处理 |

## 记录

每轮记录提交、配置、输入、轮次、声音结论、延迟分布、覆盖数量、切换与拔插次数。
记录异常原因、恢复动作和恢复时间。三轮记录齐全且各项通过后，完成彩排验收。
