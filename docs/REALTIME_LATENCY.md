# 实时延迟的组成与排查

本页说明当前实现中的等待来源。具体测量值与配置由对应实测报告维护。
组件和线程关系见[系统设计](../DESIGN.md)，测量任务见[剩余工作](../TODO.md)。

## 先确定计时范围

| 路径 | 起点与终点 | 主要等待 |
| --- | --- | --- |
| 预处理直出 | 采集输入至播放输出 | 设备 period、降噪窗口、播放缓冲 |
| 实时 RVC | 首个输入契约帧至输出契约帧 | 攒块、特征提取、合成、输出预算 |
| 原文字幕 | 识别事件发出至页面更新 | 事件读取、JSONL、SSE、浏览器处理 |
| 译文字幕 | 最终识别发出至译文发布 | 排队、复核等待、翻译与文本检查 |
| 译文播报 | 原文语音结束至实际出声 | 识别断句、翻译、任务等待、合成与播放 |

物理出声使用声学回录测量。程序中的管道写入时间用于定位软件阶段。
以任务 ID 对齐同一任务的时间线；各阶段独立统计的中位数分别报告。

## 字幕与翻译

字幕桥接主线程读取识别事件并发布原文，翻译线程顺序消费队列。
复核窗口从最终识别接收时起算，原文处理与排队均消耗该窗口。
独立播报投递线程发送 HTTP 请求，翻译线程继续处理后续任务。
字段、计时定义与队列策略见[字幕接口](../state/API.md#captions-parameters-and-speech)。

SSE 通过文件事件通知与轮询等待新内容。连接建立时先补发近期记录。
排查时同时检查识别输入、服务就绪、字幕文件增长和浏览器连接。
复核计时修复的确定性调度证据见[复核报告](../reports/refinement-deadline-20261028/RESULTS.md)。

## 合成与播放

依次拆分译文就绪、服务受理、开始处理、首块就绪和开始播放。
覆盖率优先策略保留等待任务，因此持续输入时也要记录积压与完成率。
提前输出音频允许片段生成与播放重叠；日常入口默认等待完整片段生成。
参数、运行时要求与回退方式见[提前输出说明](../tools/REALTIME_VOICE.md#提前输出音频)。

播放按逻辑任务保持顺序。变速控制使用预测时长、原声时长和积压选择比例。
控制器定义与测试配置见[灵活变速](FLEXIBLE_TEMPO.md)。
2026-10-29 对保存任务的重算及本地故障回归见[播报调查](../reports/speech-latency-20261029/RESULTS.md)。

## RVC 与直出

RVC 使用独立推理线程、滚动历史上下文与输出缓冲。
资产形状、块长和运行后端见[系统设计](../DESIGN.md#低延迟实时路径)。
启用 `MOZART_RVC_PROFILE=1` 可观察阶段耗时，性能对比另用关闭诊断的运行。
音质和导出问题按[Golden 流程](../AGENTS.md#rvc-debugging-workflow)定位。

直出绕过 RVC，测量其设备缓冲和 DSP 开销。
预处理软件段与物理声学段分别验收，方法见[预处理设计](../DESIGN_PREPROCESSOR.md#构建与验收)。

## 验证顺序

1. 固定输入、模型、设备、处理开关与提交版本。
2. 先用已有主机测试检查排队、复核等待和投递阻塞。
3. 在 Jetson 用同一输入分别测试各功能与组合运行。
4. 保存输入、输出、日志及任务时间线。
5. 核对语义、音质与完成率，再比较延迟分布。

稳定从句与句界分类器属于可选实验，启用条件与覆盖规则见[实验说明](SIMULTANEOUS.md)。
历史测量按报告日期和配置读取；本页的代码核对不产生新的板端性能结论。
