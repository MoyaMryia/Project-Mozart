# 轻量人声 DSP 实施计划

## 目标

使用 C 和 CPU 上的少量数字信号处理（DSP）算子，提高降噪后的人声清晰度。
范围包括环境噪声抑制、停顿期软噪声门、语音频带外抑制及低质量麦克风输入保护。
清晰度增强、输入保护与后处理变调分别控制，新增处理级默认关闭。
实时接线计划保留现有 48 kHz、64 样本处理节拍。
本机均衡与变调试听见[使用说明](../tools/VOICE_DSP_PREVIEW.md)。
本机音色美化试听见[美化工具](../tools/VOICE_POLISH_PREVIEW.md)。
原录音的诊断与进一步清理见[清理工具](../tools/VOICE_CLEANUP_PREVIEW.md)。

## 处理顺序

```text
预处理：原始输入监测 → 80 Hz 高通
    → 按需动态低频抑制 → 已确认频点的窄陷波
    → WOLA 降噪 → 语音检测驱动的软噪声门
    → 清晰度均衡 → 可选动态压缩 → 可选去齿音
    → 48 kHz 直出 / 16 kHz 降采样支路

后处理：48 kHz 播放信号 → 可选不变速变调 → 限幅 → 播放
```

后处理接收直出支路或 RVC 的播放输出，保留变调前的原始输出。
预处理各级接收 WOLA 实际产出的样本数，覆盖稳态小块与初始化突发输出。
清晰度增强级采用因果滤波和包络跟踪，当前块完成后直接输出。
后处理变调单独核算环形缓冲等待。

## P0：补齐低质量麦克风输入保护

先区分爆破音、短促脉冲和采集端削波，再选择对应算子。

| 问题 | 低开销方法 | 启用依据 |
| --- | --- | --- |
| 喷麦、低频爆破音 | 低频与中频包络比较，动态压低低频支路 | 低频能量短时突增 |
| 低频振动、直流偏置 | 复用现有高通 | 输入频谱与直流统计 |
| 高频嘶声、语音频带外能量 | 可选低通与高频动态衰减 | 高频噪声谱及清辅音试听 |
| 工频嗡声、稳定电磁啸叫 | Goertzel 窄带检测与少量二阶陷波器 | 静音段出现持续窄谱峰 |
| 宽带底噪、嘶声 | 现有 WOLA 谱降噪 | 停顿期噪声谱 |
| 数字跳变、短促爆点 | 检测异常样本差分，单独试听局部插值修复 | 短脉冲故障样本 |
| 采集端削波 | 统计饱和与平顶片段，指导降低采集增益 | 原始 PCM 的饱和记录 |

动态低频抑制保留原有高通，并仅在爆破音条件成立时衰减低频支路。
低通截止频率根据源采样率、噪声谱和清辅音试听选择。
陷波从确认的单个频点开始，再逐个评估谐波。
工频候选为 50/60 Hz 及其谐波；其他啸叫频点由录音确定。
噪声频点统计在低频控制路径更新，音频处理持续输出。
系数更新采用平滑切换，检测状态和最大衰减对外可查询。

需要未来样本的脉冲插值修复单独记录附加等待，默认关闭。
采集端削波会丢失波形信息；优先调整采集增益，末端限幅器保护后续处理峰值。

已完成原始录音的本机清理原型，提供动态低频衰减、低通、能量软门和离线代理谱增益。
主试听版本采用软门与谱增益；独立窄陷波实验及其尾迹见[实测报告](../reports/voice-cleanup-20261027/RESULTS.md)。

## P1：清晰度均衡与停顿期软噪声门

### 软噪声门

共享一次计算得到的语音置信度与能量统计，分别供 VAD 和软门使用。
软门采用双阈值、保持时间和增益渐变，压低停顿期背景。
首轮闭门保留衰减后的信号，并检查字头、尾音和清辅音。
包络时常数按采样率计算，保留跨块状态。

### 两个均衡算子

增加 `preprocessor/src/voice_eq.c` 和对应头文件，接入 `mozart_dsp_enhance()`。

| 算子 | 方法 | 首轮试听候选 |
| --- | --- | --- |
| 低中频整理 | 一个二阶无限冲激响应滤波器（biquad） | 250 Hz、Q=0.7、-2 dB |
| 清晰度提升 | 一个 biquad | 2.5 kHz、Q=0.7、+2 dB |

上述数值为原型候选参数。
同时生成平直、轻度和较强三个预设，逐个试听。
均衡算子只调整频谱，音高变化由 P3 的变调算子处理。
首轮三档参数与实测见[本机音色美化试听](../tools/VOICE_POLISH_PREVIEW.md)。

实施要求：

- 在配置更新时计算滤波系数。
- 在处理线程中只执行乘加和状态更新。
- 使用预分配状态和就地处理。
- 在预设切换时交叉淡化新旧输出。
- 将阶段旁路输出与原链逐样本比较。

## P2：按试听结果增加动态算子

### 轻压缩

使用峰值或能量包络、一阶 attack/release 平滑及增益映射。
候选压缩比为 `2:1`，先限制最大增益衰减。
包络按采样率更新，支持变长处理块。
attack/release 控制包络状态，音频按当前块输出。
增益曲线使用预计算表，逐样本使用查表、插值和乘法。

现有 AGC 的平滑系数按块固定。
本计划先保留 AGC 关闭，避免把固定 20 ms 的系数直接用于 64 样本块。

### 去齿音

仅在试听发现齿音过强时启用。
使用侧链带通、包络检测和有限幅度的高频动态衰减。
首轮检测频段为 `5–8 kHz`，保留独立旁路。

### 峰值保护

复用现有 `mozart_limiter_process()`，为后处理分配独立状态。
将限幅阈值和恢复系数预计算到配置状态。
限制输入输出增益，记录削波比例和最大衰减。

## P3：后处理增加一个不变速变调算子

本级用于轻量男女性效果，控制参数为半音偏移。
本机试听先使用 FFmpeg 的重采样与 `atempo` 保时长变调。
输入与输出保持相同的时长，处理输出统一为 48 kHz。

实施步骤：

1. 使用本机程序比较原始、降噪、均衡和升降 5 半音的输出。
2. 检查输出时长、基频倍率、接缝及混叠。
3. 用户确认效果后，再设计分块后处理接口。
4. 分别测量 CPU 耗时和附加缓冲等待。
5. 满足所选部署设备的预算后，再接入播放后处理。

变调使用传统 DSP，现有 RVC 保留为独立模式。

## 性能预算

P0 的无前瞻算子及 P1、P2 的设计预算如下。

- 新增算子附加音频排队：`0` 样本。
- 新增算子合计 CPU 时间：每 64 样本最大值不超过 `50 µs`。
- 计时范围：算子入口至出口，包含状态更新和预设切换。
- 运行方式：目标 CPU 单线程，48 kHz 单声道。
- 处理线程操作：预分配、就地处理、系数复用。
- 复杂数学函数：放在配置更新或低频控制更新中。

测量另覆盖 WOLA 启动突发、运行时开关和长静音后恢复。
P3 同时报告算子耗时与缓冲等待，分别判定。
整链延迟沿用 [review-pre.md](../review-pre.md) 的物理声卡基准和计时口径。

## 验收与交付顺序

1. 保留同一原始录音，另制作爆破音、短脉冲、削波及窄带干扰的合成条件。
2. 收集并标注真实低质量麦克风故障录音。
3. 分别交付输入保护、降噪、软门和均衡前后的 WAV。
4. 比较解析频响与实际扫频响应，检查滤波器稳定性。
5. 检查旁路逐样本一致、输出数量一致、有限值及无新增削波。
6. 检查任意分块、reset、静音启动和参数切换。
7. 使用原始电平与单独标注的响度匹配副本进行试听。
8. 检查字头、尾音、清辅音及持续低男声，防止误抑制。
9. 按试听结果决定 P2 的各级开关。
10. 测量算子入口至出口的 p50、p99 和最大耗时。
11. 在所选部署设备连续运行 10 分钟，检查超时、欠载和溢出。
12. 优先完成输入保护和清晰度增强，再接入简单的后处理变调。

每次只增加一个算子，并保留前一版音频和性能记录。

## 适用范围

- 计划配置：CPU 处理；48 kHz 单声道；实时接线使用 64 样本主循环；沿用现有 WOLA。
- 可复用资源：`stages.c` 的限幅器、独立开关、状态接口及用户确认的原始 30 秒录音。
- 本机离线样本数：一份用户确认的原始 30 秒录音，另有六个纯音变调条件；产物见试听程序清单。
- 未验证项：清晰度和变调的人耳验收、实时分块耗时及缓冲延迟。阻塞：本轮范围为本机离线试听；解除条件：用户确认试听效果，并按需授权实时接线和对应测量。
- 新增输入保护需求：当前录音尚未标注爆破音、削波及电磁干扰事件。阻塞：缺少对应的已标注故障录音；解除条件：制作合成条件，并收集真实故障录音进行逐项验收。
