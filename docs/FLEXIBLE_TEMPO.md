# 灵活变速与轻量时长模型

系统逐段计算播放比例。它使用当前音色的预测时长、源音频观测区间和积压反馈。
默认范围为 1.000–1.150 倍，精度为 0.001。默认不减速。
1.15 倍是按用户要求提高的上限，不是固定播放速度。
此前的 Jetson 整机延迟和识别质量结果只覆盖当时的 1.05 倍上限。
新上限的对照结果见 [1.15 倍验证报告](../reports/tempo-limit-20261016/RESULTS.md)。
每个逻辑任务固定一个比例；任务内的音频块共用过滤器，保留过滤器状态和完整尾部。
预览保持原速。文本、顺序及原速下载 WAV 保留。

## 比例控制

控制器先计算两项需求：

- 时长比例：`预测播报时长 / 本段源音频观测时长`。生成已完成时，优先使用实测播报时长。
- 积压比例：`1 + max(0, 当前延迟 - 目标延迟, 其他待播时长 - 目标延迟) / 恢复时间`。

控制器取两项需求与原速的最大值，再限制到配置上限。
需求超过上限时，任务保留 `limited=true`，并记录尚不能消除的预测时长差。
控制器不会通过删字、漏句或打乱顺序满足预算。
控制器立即响应加速需求。相邻决策每次最多降低 0.010 倍；5 s 没有新决策后清除该音色的速度历史。

默认目标延迟为 1.5 s，恢复时间为 30 s。这些是控制参数，不是延迟保证。
当前延迟从源识别事件发出计到播放决策；缺少源时间戳时，从任务提交计时。
其他待播时长使用容量估计，包含队列中的后续任务。
它不是物理扬声器的实际剩余播放量。

## 四参数时长模型

模型使用带正则项的线性回归。四个参数分别对应常数项、词数、近似音节数和分句标点数。
近似音节数来自字母规则，不是逐音素对齐。
训练工具需要 NumPy，运行时不需要 NumPy、PyTorch 或额外推理服务。
模型只预测完整合成音频的时长，不生成译文，也不改写译文。

内置配置为 Qiqi 参考音色、PocketTTS、CPU int8、5 步、种子 42。
配置检查音色修订、引擎参数、运行时版本、流式协议和 ONNX 文件 SHA-256。
不匹配时，系统使用保守粗估。
数字、全大写缩写、非 ASCII 文本及超出训练词数范围的文本同样回退。
新模型保留原有容量估计，并加入训练残差得到的余量。
该余量不是单句时长误差的硬上限。

训练数据来自已保存的 120 s 回放：23 个父字幕、41 个播报任务、47 个合成文本片段。
各片段的时长已与 WAV 采样数核对。
训练只使用英文文本及其实际合成时长，不能把这些未经校对的译文作为翻译质量标签。
按父字幕留出的结果用于探索性比较；另用 12 条未参与训练的固定文本检查预测误差。

## 源音频区间

普通字幕使用音频开始与结束时间戳之差。
早期分句只使用上次提交后新增的观测区间，避免多个分句重复分配父段总时长。
观测区间包含识别前视音频，不等于分句的精确发音区间。
更正播报不复用此前的源时长预算。
缺少有效时间戳时，控制器只使用积压反馈。

## 配置与诊断

启动器和独立播报服务默认使用 `--playback-tempo flexible`。
以下参数可覆盖默认值：

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| `--playback-tempo-max` | `1.15` | 播放比例上限。允许 1.00–1.15，向下取到 0.001 精度。高于 1.05 的发音与听感仍需另测。 |
| `--playback-target-delay` | `1.5` | 目标延迟，单位为秒。 |
| `--playback-recovery-seconds` | `30` | 分摊积压的时间，单位为秒。 |
| `--duration-profile` | 内置 Qiqi 配置 | 经过标定的时长模型 JSON。加载失败时回退，并报告原因。 |
| `--capture-playback` | 关闭 | 保存实际过滤后的 WAV，供完整性和听感对照。 |

使用 `--playback-tempo adaptive` 恢复旧两档策略。
使用 `--playback-tempo-max 1.05` 恢复此前灵活变速的上限。
使用 `--playback-tempo normal` 恢复原速。
任务的 `duration_prediction` 报告模型、粗估原因、预测时长和余量。
任务的 `tempo_decision` 报告原始需求比例、选定比例、积压和上限限制。
`predicted_unserved_seconds` 只表示该段相对源区间的预测超长量，不是累计积压或实测延迟。

复现标定时，先准备原始回放与独立合成结果，再运行：

```bash
python3 rvc-golden/fit_speech_duration.py \
  --replay rvc-golden/playback-latency-20261015/replays/backlog-library-confirmed-20261015 \
  --independent rvc-golden/flexible-tempo-20261015/holdout-results.json \
  --profile tools/duration_profiles/qiqi-pocket.json \
  --report rvc-golden/flexible-tempo-20261015/duration-fit.json
```

论文依据见[译文时长调研](TRANSLATION_DURATION.md)。
实测范围与剩余限制见[本轮报告](../reports/flexible-tempo-20261015/RESULTS.md)。
